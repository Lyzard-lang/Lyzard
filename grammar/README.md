# LYZARD.tmLanguage

TextMate-compatible syntax highlighting grammar for the [LYZARD](https://github.com/lyzard-lang/lyzard) programming language.

## Features

- Keywords (`fn`, `let`, `mut`, `return`, `if`, `else`, `while`, `for`, `match`, `spawn`, `select`, etc.)
- Built-in types (`int`, `float`, `bool`, `str`, `char`, `void`)
- String and character literals with escape sequences
- Numeric literals (decimal, hex, binary, octal, float)
- Block comments (`/- ... -/`) and line comments (`-- ...`)
- Operators and punctuation
- Pattern matching syntax
- Enum and struct definitions
